about=ScruTech exposes the ScruTech projects as QGIS Processing tools, each driven by a simple area of interest. VegeVigie: Sentinel-2 datacube, cloud masking, NDVI monthly composites, per-pixel Mann-Kendall + Sen's slope trend and NDVI-anomaly drought stress, aggregated to zones. AlphaEarth: year-to-year change from Google satellite embeddings (needs a Google Earth Engine service-account key). PAFF (forest fire): the Wildland-Urban Interface, frontier line and contact band between forest and built-up areas (débroussaillement / defence zone). Écobuage: weighted multi-criteria controlled-burn aptitude (0-100 map + 3-class zoning). Biotrame: hexagonal priority mesh crossing biodiversity reservoirs, corridors and wetland potential. GeoAI (experimental): zero-shot raster segmentation with Meta's Segment Anything Model, downloaded once from the official open-source release (Apache-2.0) and cached locally. The area-of-interest tools run in an external Python environment that has their stack (datacube / GeoPandas / DuckDB); the advanced PAFF and écobuage tools (layers in) use only native QGIS (GDAL/numpy/QgsGeometry), with no extra dependencies and no internet.

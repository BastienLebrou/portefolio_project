# geoai-py 0.43.1

**Quoi.** Nouvelle version de [[geoai-py]] par [[Qiusheng Wu]] : une seule bibliothèque pour PyTorch, Transformers, les modèles de segmentation et les données spatiales (images et vecteurs). Documentation, notebooks et extension QGIS.

**Pourquoi ça compte.** Le point d'entrée gratuit le plus simple pour passer d'une démo Hugging Face à une chaîne Sentinel / orthophoto / SAM.

**Lien ScruTech.** Candidat direct pour VegeVigie (segmentation végétation, eau, bâti sur Sentinel-2) à la place d'un modèle maison.
